MedSport Monitor — حزمة المشروع
================================

تشغيل الواجهة الأمامية فورًا:
- افتح MedSport-تشغيل-مباشر.html من المتصفح، أو
- شغّل launch-frontend.bat في Windows (يفتح index.html).
لا يلزم تثبيت برامج لعرض الواجهة التجريبية.

محتويات الحزمة:
- index.html + styles.css + app.js: واجهة عربية تفاعلية ببيانات تجريبية.
- MedSport-تشغيل-مباشر.html: نسخة مستقلة في ملف HTML واحد.
- original-project/MedSportMonitor-main/: ملفات المشروع الأصلي كاملة، كما وردت في الأرشيف.

تنبيه: الواجهة الأمامية للعرض السريع ليست مربوطة بقاعدة بيانات أو MQTT أو خدمة
التحليلات الأصلية. تشغيل التطبيق الأصلي منفصل ويتطلب Java 21 وPython 3.11+؛
راجع original-project/MedSportMonitor-main/README.md وتعليمات التشغيل داخله.
بيانات الواجهة تجريبية فقط وليست للاستخدام الطبي أو التشخيص.
